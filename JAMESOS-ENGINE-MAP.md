## Implementation constraints

- MACRO has four models: CHORD, SWARM, ADDTV and SPEECH. It is Plaits-inspired, not the full Plaits engine.
- DIGITAL is Clipper's four-operator FM engine; FM6 and FMX are separate six-operator engines.
- PHYS includes physical string and modal models.
- GRAIN in Clipper synth mode uses four bundled, synthesized source sets (VOX, GLASS, PAD and AIR), generated by `tools/gen_clipper_sets.py`; JAMESOS uses PAD, GLASS and AIR. These are built-in synthesis assets, not recordings and not user-supplied samples.
- H/T/M percentages map directly to MACRO HARM/TIMB/MORPH only. Other engines use engine-specific parameter translations.
- All 50 entries are also registered in Clipper's global factory preset browser as one contiguous `JAMESOS` category, in original ID order. The normal engine filter remains available, and the category label identifies the collection.
- The 12 three-track combinations remain performance reference material: Clipper synth mode is one instrument with an optional layer, not a three-independent-track groovebox.
- Drum systems remain out of scope. Do not re-enable drum lanes or add drum presets.
